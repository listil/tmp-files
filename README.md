# tmp-files

## 추천 오버레이 (Windows)

다운로드: [Releases](https://github.com/listil/tmp-files/releases/latest)

### 권장 화면 설정

| 항목 | 권장값 |
|---|---|
| 게임 화면 모드 | **창 없는 전체 화면** (테두리 없는 창 모드) |
| 해상도 | **3840×2160** (16:9) |
| Windows 디스플레이 배율 | **125%** |

- **독점 "전체 화면" 모드에서는 오버레이가 보이지 않습니다.** 반드시 "창 없는 전체 화면"을 쓰세요.
- 화면 인식 좌표는 위 설정에서 맞췄습니다. 다른 16:9 해상도(2560×1440, 1920×1080 등)는 비율로 환산해 동작하지만 실측 검증은 3840×2160만 했습니다.
- **2560×1600 창 모드(16:10)**도 실제 게임 화면으로 맞춰 두었습니다. 창 모드에서는 게임 창 위에 다른 창(브라우저, 메신저 등)이 겹치면 그 부분이 같이 캡처되어 인식이 틀립니다.
- 배율 150%에서도 동작을 확인했습니다. 패널 위치가 어긋나면 패널 제목을 끌어 옮기면 위치가 저장됩니다.
- 여러 모니터를 쓰는 경우 모니터마다 배율이 달라도 게임이 떠 있는 모니터 기준으로 맞춰집니다.

### 설치

1. Releases에서 `Overlay-Setup-x.x.x.exe`를 받아 실행합니다.
2. 코드 서명이 없는 파일이라 "Windows의 PC 보호" 창이 뜹니다. **추가 정보 → 실행**을 누르세요.
3. 시작 시 실시간 캡처는 꺼져 있습니다. 패널의 "실시간 캡쳐" 버튼을 켜거나 "캡쳐 1회"를 누르세요.
4. 종료는 작업 표시줄 오른쪽 트레이 아이콘을 우클릭 → 종료입니다.
